Polycrystalline Tungsten DDD Workflow

A modular workflow for Neper-based microstructure generation, grain-dependent BCC slip selection, Frank-Read source initialization, OpenDiS evolution, and reproducible network analysis.

Explore the code Paper example

From prescribed sources to collective evolution

The framework follows the bow-out, loop formation, and multiplication of initially prescribed Frank-Read sources in a crystallographically heterogeneous polycrystal. The calculation provides a mesoscale view of how dislocation activity becomes grain dependent and how increasing line density raises network resistance.

The public repository separates configuration, crystallography, slip-system selection, Neper handling, OpenDiS execution, quantitative metrics, and VTK export into reusable modules.

Reproducible workflow

1. MicrostructureGenerate the grain geometry and neighborhood topology with Neper.
2. SourcesSelect BCC slip carriers and initialize grain-confined Frank-Read sources.
3. EvolutionEvolve the nodal network through the OpenDiS Python interface.
4. AnalysisExport ParaView-ready networks and quantitative density histories.
